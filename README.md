# Gallup Flash-Flood GIS Map Builder

Student site: <https://neilken.github.io/map/>

This static classroom activity advances Engineering Essentials Unit 1.4 from reading GIS evidence to creating a point, line, and polygon layer. Real Gallup basemaps and landmarks are combined with clearly labeled fictional emergency conditions.

## Teacher records

The site reports starts, scored checkpoint attempts, autosaves, and final maps to a separate Google Apps Script logger. The linked workbook contains `Attempts`, `Student Summary`, and `Final Maps` tabs. The browser also saves work locally so an accidental refresh does not erase progress.

## Classroom note

All flood zones, closures, needs, capacities, facility availability, and emergency uses are fictional. The activity is not a source of real emergency information.
